# DESIGN.md — UI/UX Design System Specification
**Style:** `radix-vega` (shadcn UI)  
**Theme:** Dark Theme Primary (Slate/Neutral Palette)  
**Typography:** Geist Sans / Inter  
**Accent Color:** Emerald (Inventory/Active), Indigo (Analytics), Amber (Pending), Rose (Late)

### Layout Wireframe
- **Desktop:** Collapsible Left Sidebar (240px) + Header with User Avatar & Company Badge + Dynamic Breadcrumbs.
- **Mobile:** Bottom Navigation Bar + Top Header with Slide-over Drawer (`Sheet`).
